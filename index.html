About

I'm a data scientist focused on experimentation, machine learning, and AI / LLM systems. I turn high-stakes data into decisions — defining metrics, designing and analyzing A/B tests, and evaluating whether a model (statistical or LLM-based) is reliable enough to ship.

Rigor and reproducibility are defaults, shaped by work in regulated, high-stakes settings including the Federal Reserve Board: experimentation with power / MDE and CUPED variance reduction, confidence calibration and uncertainty quantification, and Python / SQL pipelines that are auditable end to end.

Most of my recent work is in applied AI — building and evaluating LLM and agentic systems (RAG and agent workflows) for reliability, calibration, and evidence grounding, with human-in-the-loop review. The question I care about most: does this model actually do what it claims?

Applied AI research

agentic-ai-evaluation-platform

A reproducible study of LLM-based QA agents on synthetic model-monitoring anomaly review: 15 labelled scenario types, transparent feature engineering and a deterministic rule baseline, a schema-constrained agent with retry / validation, an optional second-pass reviewer agent, four prompt conditions, and an evaluation suite spanning precision / recall, confidence calibration (ECE, Brier), unsupported-claim analysis, and paired statistical testing (McNemar, paired permutation, Benjamini–Hochberg). How I use AI tools

I treat AI coding tools as collaborators on boilerplate, refactoring, and documentation — not as substitutes for analyst judgment. Every repo that uses an LLM in its workflow includes a CLAUDE.md defining how the model should behave, a clear human-review step before outputs are shared, and explicit limitations of what the AI-assisted output represents.
